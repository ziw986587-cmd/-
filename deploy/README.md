# 部署说明

本目录提供通用模板，不包含现有服务器账号、密码、站点配置或生产数据。

1. 安装 Node.js 20+、Python 3.10+ 和 Nginx。
2. 将源码放置到 `/opt/local-center`，创建独立服务账户 `local-center`。
3. 创建 `/opt/local-center-data`，赋予服务账户读写权限。升级已有环境前先完整备份代码和数据，不用空数据覆盖旧目录。
4. 复制 `local-center.service` 至systemd配置目录，将 `__PUBLIC_ORIGIN__` 替换为实际公网来源。
5. 参考 `nginx.conf.template` 设置实际主机名和端口，转发到 `127.0.0.1:8777`；为正式域名配置HTTPS。
6. 加载并启动服务，检查日志、后台访问、会员入口和开奖源状态。
7. 新安装先修改默认管理员密码、用户操作密码和房间访问密码，再分发会员专属链接。

数据目录中的 `database.json` 包含后台身份信息；`rooms/state.json` 及可能存在的 `rooms/state.overlay.json` 包含房间业务数据。完整备份必须包含整个数据目录。恢复时应停止服务，保留原始备份并核对余额账本。

本次发布以2026-10-10的当前源码为准。详细生产部署历史属于运维记录，没有收入公开仓库。仓库不会自动连接或更新原服务器。
