# 番摊代码

会员前台、管理后台及房间服务的完整源码快照，整理于2026-10-10。
包括加拿大28、澳洲8、澳洲3，共享积分、会员管理、机器人回复、开奖源适配、历史记录、返水统计及7天业务记录保留逻辑。

## 本地运行

准备 Node.js 20+ 和 Python 3.10+。程序本身使用标准库，不需要安装 npm 或 pip 依赖。

```sh
node server.js
```

Windows也可以双击“启动本地网站.cmd”。

- 后台：<http://127.0.0.1:8777/admin>
- 前台：<http://127.0.0.1:8777/portal>
- 全新安装管理员：`localadmin`，初始密码：`LocalDemo2026!`。
- 全新安装用户操作密码默认为 `admin123`；上线前在后台“修改密码”中修改各类初始密码，并设置房间访问密码。
- 会员由后台创建，使用后台生成的个人专属链接进入。个人链接等同访问凭据。

这些是源码默认值，不是现有服务器的数据或密码备份。本仓库不包含会员、余额、订单、个人链接、运行日志和生产数据。首次启动会创建独立的本地数据目录。

## 目录

- `server.js`：Node HTTP服务及访问控制。
- `portal.*`：会员前台。
- `app.js`、`workbench.*`、`room-admin.*`：管理后台。
- `room-engine/`：Python房间服务、账本、结算、开奖源适配、数据保留等。
- `avatars/`：108张头像及授权说明。
- `tests/`：现有自动测试；`legacy/`：兼容代码与测试。
- `deploy/`：通用部署模板及开奖接口适配说明。

## 数据与7天保留

三个房间共用会员余额。历史业务记录滚动保留7天，每5分钟检查过期数据；会员资料、当前余分、房间设置和未完成订单、待审核申请保留。旧账本明细压缩为期初汇总，以便持续核对余额。

运行数据与源码分开保存，GitHub源码不能用于恢复已有会员余额。恢复生产环境需另行持有完整数据备份。

## 环境变量

| 变量 | 用途 |
| --- | --- |
| `PORT` | 本机端口，默认8777 |
| `LOCAL_CENTER_DATA` | 数据目录，默认当前目录下data |
| `LOCAL_CENTER_PYTHON` | Python可执行文件路径 |
| `PUBLIC_ORIGIN` | 反向代理后的实际公网来源，例如https://example.com |

部署步骤见 [deploy/README.md](deploy/README.md)。源码包含原有开奖源适配器，实际可用性与配置应在部署环境独立验证；不要把接口Token写进Git仓库。

## 检查

```sh
node --test tests/*.test.js
python -m unittest discover -s tests -p "test_*.py"
```

测试在临时目录创建隔离数据。部分旧集成测试可能需要相应运行环境；源码归档不代表已经完成全部测试或100～200人容量验证。
